## 1 参考NIST MCE读出架构

美国国家标准与技术研究院（NIST）与加拿大不列颠哥伦比亚大学（UBC）联合开发的面对大规模TES阵列时最经典、应用最广泛的室温与低温联合读出架构，分为极低温、温区过渡段和室温三个部分：

### 1.1 极低温端：SQUID 时分复用（TDM）

在稀释制冷机的最深处，TES 像素被排列成 M×N的二维矩阵。

- **第一级SQUID**：每个TES像素都电感耦合到一个Input SQUID作为微弱电流放大器。
- **行扫描切换**：逐行给 SQ1 的偏置线（Bias Line）供电，按顺序在几百纳秒内轮流开启第 1 行、第 2 行……第M行。
- **列信号汇总**：同一列所有行的 SQ1 输出端串联在一起，共享一根信号线拉到更高温区。这种时分复用（TDM）将原本需要M×N组的引线，降到了M+N组，确保制冷机不会因为导热而漏热。

### 1.2 中间温区（4K）：SQUID 阵列放大

由于第一级SQUID的输出极其微弱（纳伏级），信号在拉出制冷机前，会在4K温区通过一个由上百个 SQUID 串联组成的 SQUID 阵列进行二次放大，将其输出阻抗提高到约100Ω，以匹配室温电子学。

### 1.3 室温端：多通道电子学

基于 FPGA 的高速数字/模拟混合电路板。

## 2 工作机制

上位机拿到的“原始数据”并不是ADC的直接采样值。使用了磁通锁定环（Flux-Locked Loop, FLL）的硬件算法。FPGA 实时计算出来的 PID 反馈值。

- **动态采样**：当系统切换到第 $i$ 行时，ADC 采样当前列的输出。
- **硬件 PID 计算**：FPGA 内部的误差器会计算当前输出偏离“最佳工作点”的距离，并通过数字 PID 算法立刻算出一个补偿值。
- **闭环反馈**：FPGA 通过反馈 DAC 向该行/该列的 SQUID 反馈线圈施加一个反向磁通，把 SQUID “硬生生”拽回线性度最好的陡峭位置。
- **数据输出**：这个由 FPGA 实时计算出来的 PID 反馈值，就是最精确的、与 TES 电流完全成正比的物理测量数据。

## 3 数据结构与通信标准（固定长度二进制命令帧）

**IPbus** (μHAL) CMS/ATLAS片上FPGA控制UDP二进制，寄存器读写。(适合极大的读出通道，需要在板子里移植并跑通官方的 IPbus Firmware 固件。)
**NIST MCE 读出固定长度二进制帧，命令字+板地址+参数地址+数据。**

| 32-bit 字                   | 最高字节 (MSB)   | 次高字节             | 次低字节 | 最低字节 (LSB) |
| --------------------------- | ---------------- | -------------------- | -------- | -------------- |
| **Word 0 (指令头)**   | SYNC_H (0xAA)   | SYNC_L (0x55)       | CMD      | BOARD_ID       |
| **Word 1 (控制路由)** | PARAM_ID         | CHANNEL_STATE (0/1) | ROW_ID   | COL_ID         |
| **Word 2 (数据负载)** | VALUE            | VALUE                | VALUE    | VALUE          |
| **Word 3 (校验尾)**   | RESERVED (0x00) | RESERVED (0x00)     | CRC16_H  | CRC16_L        |

### 3.1 帧结构（16字节）

| Byte  | Field         | 说明                    |
| ----- | ------------- | ----------------------- |
| 0     | SYNC_H        | 帧同步高字节，固定 0xAA |
| 1     | SYNC_L        | 帧同步低字节，固定 0x55 |
| 2     | CMD_TYPE      | 命令类型（见下表）      |
| 3     | BOARD_ID      | 板卡编号 0x01~0x07      |
| 4     | PARAM_ID      | 参数编号（见下表）      |
| 5     | CHANNEL_STATE | 通道状态，开关0/1       |
| 6     | ROW_ID        | 行号 0~19；0xFF=全行    |
| 7     | COL_ID        | 列号 0~15；0xFF=全列    |
| 8~11  | VALUE         | 32-bit                  |
| 12~13 | RESERVED      |                         |
| 14~15 | CRC16         | CRC校验                 |

### 3.2 CMD_TYPE 定义

```
CMD_WRITE = 0x01 # 写参数，期待 ACK 
CMD_READ_REQ = 0x02 # 请求读取参数 
CMD_READ_RESP = 0x03 # 板卡回复读取结果 
CMD_ACK = 0x04 # 操作成功确认 
CMD_ERROR = 0x05 # 错误回复（VALUE字段传错误码）
CMD_BATCH_REQ = 0x06 # 批量写入请求头
CMD_SYNC_REQ = 0xF0 # 心跳/握手查询 
CMD_SYNC_RESP = 0xF1 # 心跳回复
```

### 3.3 BOARD_ID 与 PARAM_ID

```
# ---- BOARD_ID ----
BOARD_BIAS1    = 0x01   # 偏置源板卡1（TES信号，16列）
BOARD_BIAS2    = 0x02   # 偏置源板卡2（SA Ib/phix, Vb，16列）
BOARD_BIAS3    = 0x03   # 偏置源板卡3（IS I/phib，16列）
BOARD_ADC      = 0x04   # ADC读出板
BOARD_FB_DAC   = 0x05   # FB DAC板
BOARD_GATE_DAC = 0x06   # 选通DAC板（20行）
BOARD_FPGA     = 0x07   # FPGA汇总板

# ---- PARAM_ID ----
PARAM_ENABLE       = 0x01   # 通道使能，VALUE=0/1
PARAM_TES_V        = 0x02   # TES偏置电压 (V)
PARAM_SA_IB        = 0x03   # SA 偏置电流 (μA)
PARAM_SA_PHIX      = 0x04   # SA 磁通偏置 (μA)
PARAM_VB           = 0x05   # TES Vb (V)
PARAM_IS_I         = 0x06   # IS 偏置电流 (μA)
PARAM_IS_PHIB      = 0x07   # IS 磁通偏置 (μA)
PARAM_GATE_DAC     = 0x08   # 选通DAC电压 (V)
PARAM_GATE_OFFSET  = 0x09   # 选通DAC偏置 (V)
PARAM_FB_DAC       = 0x0A   # 反馈DAC输出 (V)
PARAM_AC_FREQ      = 0x10   # 交流信号频率 (Hz)
PARAM_AC_AMP       = 0x11   # 交流信号幅值 (μA)
PARAM_WAVEFORM     = 0x12   # 波形类型 0=正弦 1=方波 2=三角
PARAM_DC_VALUE     = 0x13   # 直流电流值 (μA)

```

### 3.4 批量写入帧

| Byte  | Field       | 说明                              |
| ----- | ----------- | --------------------------------- |
| 0~1   | SYNC 0xAA55 |                                   |
| 2     | CMD = 0x06  | 批量写入                          |
| 3     | BOARD_ID    |                                   |
| 4     | PARAM_ID    |                                   |
| 5     | N_CH        | 通道数量（最多 20）               |
| 6~7   | CH_MASK     | 位掩码，bit i=1 表示通道 i 有效   |
| 8~N   | VALUES      | 每通道 4 字节 float32，按通道顺序 |
| N~N+1 | CRC16       |                                   |
